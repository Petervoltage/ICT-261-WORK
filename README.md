# SimpleJavaFXApp

A JavaFX application built with Gradle for the ICT 261 (Introduction to Object Oriented Programming and Java) module.

## 🚀 Prerequisites

Before running this project, ensure you have the following installed:

* **Java Development Kit (JDK):** Version 17 or higher (Java 21 recommended)
* **Gradle:** (Gradle Wrapper `./gradlew` or local installation)
* **IDE:** IntelliJ IDEA (Recommended) or VS Code
